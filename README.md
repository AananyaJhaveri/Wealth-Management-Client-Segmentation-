# Wealth Management Client Segmentation & Goal Readiness Analysis

## Project Overview

An independent financial analytics and machine learning project focused on analysing synthetic client profiles, identifying meaningful client segments and evaluating investment goal readiness.

The project demonstrates how data analytics and unsupervised machine learning can support client segmentation and financial decision-making.

## Objectives

- Analyse financial client characteristics.
- Explore income, savings and investment patterns.
- Segment clients using K-Means clustering.
- Apply Principal Component Analysis (PCA) for dimensionality reduction.
- Examine simulated risk preferences and investment goals.
- Evaluate emergency fund status and goal readiness.
- Translate analytical findings into business insights.

8. Client segment profiling.

## Dataset Description

The notebook generates 3,000 synthetic client profiles with financial characteristics such as:

- Age
- Annual income
- Monthly expenses
- Total savings
- Investment value
- Investment horizon
- Simulated risk tolerance
- Investment goals
- Employment type

## Disclaimer

All client profiles and financial records used in this project are synthetically generated for educational and analytical purposes.

They do not represent real individuals, actual investors, Morgan Stanley clients or confidential financial information.

The simulated assumptions and results are illustrative and should not be interpreted as actual market statistics, investment recommendations or professional financial suitability assessments.
